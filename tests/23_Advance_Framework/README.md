# Module 23: Advanced Framework

This module covers enterprise-level Playwright framework design.

## Planned Topics

- **Global Setup/Teardown**: `globalSetup` and `globalTeardown` in `playwright.config.ts`
- **Worker-Level Fixtures**: shared state across tests in a worker
- **Project Configuration**: multiple browser projects in `playwright.config.ts`
- **Sharding**: splitting tests across CI machines with `--shard=1/4`
- **Custom Reporters**: HTML, JSON, Allure, and custom reporter classes
- **Environment Variables**: `.env` files with `dotenv` for secrets management
- **Monorepo Patterns**: organizing tests across multiple apps
